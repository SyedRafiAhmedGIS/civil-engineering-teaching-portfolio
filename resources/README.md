# Teaching Resources — Verified Index

Curated by **Syed Rafi Ahmed** ([github.com/SyedRafiAhmedGIS](https://github.com/SyedRafiAhmedGIS))

These pages support the three courses documented in this repository. Each entry states who it
suits (first-year student, lab instructor, or advanced learner) and one concrete way I would use
it in class. Selection criteria: free to access, current, from an identifiable source, and
useful for teaching rather than general browsing.

## Verification

Every link was opened and checked in October 2026: the page loaded, the title matched the
listing, and the content matched the description. Two entries (marked with a note) block
automated access but open normally in a browser — please double-check those manually.
A weekly GitHub Actions workflow re-checks all Markdown links automatically
(`.github/workflows/link-check.yml`); see `mlc_config.json` for the ignore list.

## Suggesting a resource

Open an issue or pull request following the rules in [`CONTRIBUTING.md`](../CONTRIBUTING.md):
resources must be free to access, current, verifiable, and described in the contributor's own
words. Official standard texts (ASTM, BS EN, IS, BDS EN, BNBC) are copyrighted and are cited by
number only — links point to the issuing body, never to pirated copies.
