# Introductory GIS — Course Documentation

One-semester (13-week) documentation package for a first course in geographic information
systems aimed at civil engineering students. All materials are original.

| File | What it contains |
|---|---|
| `syllabus.md` | One-page syllabus: description, outcomes, assessment split, software |
| `weekly-plan.md` | Week-by-week topics, labs and assessment |
| `outcomes-assessment-map.md` | Matrix linking each course outcome to assessments |
| `lecture-01-what-is-gis.md` | Sample lecture outline 1 |
| `lecture-02-coordinate-reference-systems.md` | Sample lecture outline 2 |

**Status:** syllabus, weekly plan, outcome map and two sample lecture outlines complete.
QGIS lab workbooks and full slide decks: *planned, not started - see ROADMAP.md* (the sample outlines define the
format all remaining lectures will follow).

**Companion code:** `code/gis_demo/gis_intro_demo.py` (and its Colab notebook) provides a
dependency-light taste of spatial interpolation and choropleth mapping for week 1-2 labs,
so every student sees a map rendered from data in the first fortnight, before installing
QGIS.
