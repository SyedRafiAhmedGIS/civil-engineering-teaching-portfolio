# Concrete Technology — Course Documentation

One-semester (14-week) documentation package for a first course in concrete technology,
typical of the second year of a civil engineering programme. All materials are original
and written for classroom use; no textbook pages are reproduced.

| File | What it contains |
|---|---|
| `syllabus.md` | One-page syllabus: description, outcomes, assessment split, texts |
| `weekly-plan.md` | Week-by-week topics, activities and reading prompts |
| `outcomes-assessment-map.md` | Matrix linking each course outcome to assessments |
| `lecture-01-introduction-cement-hydration.md` | Sample lecture outline 1 |
| `lecture-02-fresh-concrete-workability.md` | Sample lecture outline 2 |

**Status:** syllabus, weekly plan, outcome map and the two sample lecture outlines are
complete. Full slide decks for all 14 weeks: *planned, not started - see ROADMAP.md* (the two sample outlines define
the template every remaining lecture will follow).

**Companion material:** the laboratory session for this course is documented in
`lab-manual/concrete-slump-cube-test/`, and the analysis toolkit in `code/concrete_analysis/`
(US / UK / India / Bangladesh standards) is ready for use in lab sessions.
