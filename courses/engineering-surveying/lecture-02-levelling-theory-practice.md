# Lecture 2 Outline — Levelling: Theory and Field Procedure

**Duration:** 50 minutes · **Format:** lecture + instrument demo ·
**Course:** Engineering Surveying · **Week:** 3 (levelling block)

## Learning objectives

Students will be able to: (1) define datum, reduced level, backsight/foresight/intersight;
(2) reduce a level run by both rise-and-fall and height-of-instrument methods; (3) compute
misclosure against a tolerance proportional to the square root of kilometres run; and
(4) explain collimation, curvature and refraction corrections and when each matters.

## Slide deck (titles and key points)

1. **What levelling actually measures**
   - Elevation differences, not elevations; datums and benchmarks
2. **The level and the staff**
   - Automatic compensator; bubble check; staff zero; reading to 1 mm
3. **Booking methods side by side**
   - Rise-and-fall vs height-of-instrument; same run, two sheets, same answer
4. **The arithmetic check**
   - sum(BS) - sum(FS) = last RL - first RL; why this catches maths but not misreads
5. **Closure and tolerance**
   - Acceptable misclosure scales with distance; example: 12 mm root-km rule
6. **Corrections that matter**
   - Collimation (equal-length sights), curvature + refraction (long sights), staff tilt
7. **Live instrument demo**
   - One setup, four staff stations, class reads and books in real time
8. **Wrap-up clicker**
   - Two readings swapped in a booked run - does the arithmetic check catch it? (No!)

## In-class activities

- Live instrument demonstration (12 minutes) with class-wide booking; the demo run is later
  re-used as the worked example in the tutorial.
- Clicker question on the arithmetic check's blind spot (booking transposition) - sets up
  the "check from independent observation" principle from Lecture 1.

## Assessment hook

Week 3-4 fieldwork produces the first marked notebook entry: a closed level run reduced by
both methods with the arithmetic check. Misclosure beyond tolerance requires a documented
re-run, not an adjustment fudge - recorded honestly as part of the mark.

## Common misconceptions to address

- "The arithmetic check proves the run is correct" - it only checks the arithmetic.
- "More decimal places means more accuracy" - precision of booking reflects the instrument.
