# Engineering Surveying — Course Documentation

One-semester (14-week) documentation package for a first course in engineering surveying.
All materials are original; no textbook pages or proprietary lab sheets are reproduced.

| File | What it contains |
|---|---|
| `syllabus.md` | One-page syllabus: description, outcomes, assessment split, texts |
| `weekly-plan.md` | Week-by-week topics, fieldwork and assessment |
| `outcomes-assessment-map.md` | Matrix linking each course outcome to assessments |
| `lecture-01-surveying-principles-errors.md` | Sample lecture outline 1 |
| `lecture-02-levelling-theory-practice.md` | Sample lecture outline 2 |

**Status:** syllabus, weekly plan, outcome map and two sample lecture outlines complete.
Field-manual templates and full slide decks: *planned, not started - see ROADMAP.md* (the sample outlines define the
template all remaining lectures will follow).

**Why the course is built this way:** every theory block is paired with a field or desk
exercise, and every field exercise produces data the student must close, adjust and defend
- the same discipline the `code/` toolkit applies to concrete data.
